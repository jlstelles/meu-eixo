# FitLite Pro

Arquivo único (`index.html`), sem dependências nem build. Publique copiando para a pasta do site (HTTPS é necessário para GPS e rádios).

Dados ficam no navegador (localStorage). Nuvem opcional: repositório GitHub **privado** de dados, com token fine-grained (Contents: Read and write). O token não entra no backup.

Não substitui profissional de saúde.

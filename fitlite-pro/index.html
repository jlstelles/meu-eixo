Nuvem (GitHub)

Guarda uma cópia dos seus registros em um repositório privado seu no GitHub, para você ver e analisar no computador. Sem conexão, o app continua funcionando e envia depois.

Como criar o token (uma vez, uns 3 minutos)
  1. No GitHub, crie um repositório privado só para os dados (ex.: fitlite-dados). Não use o repositório do código.
  2. Vá em Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token (os nomes dos menus podem mudar).
  3. Em “Repository access” escolha “Only select repositories” e marque só o repositório de dados.
  4. Em Permissions, Repository permissions, deixe Contents: Read and write. Nada mais.
  5. Defina uma validade (ex.: 90 dias), gere, copie o token e cole aqui.

O token fica salvo somente neste navegador, não entra no backup e não vai para lugar nenhum além do GitHub. Quem tiver acesso ao seu celular desbloqueado pode usá-lo: se perder o aparelho, apague o token no GitHub.

Arquivos no repositório: fitlite/dados.json (tudo) e fitlite/resumo-diario.csv (uma linha por dia, abre no Excel). O GitHub guarda o histórico de versões.

Backup dos dados

Seus registros ficam só neste aparelho. Se você trocar de celular ou limpar os dados do navegador, eles podem se perder. Exporte uma cópia de vez em quando e guarde o arquivo em local seguro (ele não é criptografado). O token da nuvem não entra neste arquivo.
